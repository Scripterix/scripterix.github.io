# Scripterix Studio

**Aplikacje webowe · Automatyzacje · Narzędzia AI**

## Programuję narzędzia, które rozwiązują konkretne problemy.

Tworzę aplikacje webowe, skrypty i automatyzacje. Pracuję z JavaScript, TypeScript, React i Pythonem. Wykorzystuję agentów AI do szybszego rozwijania, testowania i sprawdzania oprogramowania.

### W czym mogę pomóc?

**01 / Aplikacje i poprawki**

Buduję panele administracyjne, formularze, katalogi produktów i niewielkie aplikacje. Rozwijam istniejący kod, dodaję funkcjonalności i naprawiam błędy.

**02 / Pliki, dane i automatyzacje**

Tworzę skrypty do przetwarzania CSV, JSON i danych z API. Projektuję importy, walidację, raporty błędów i automatyzację powtarzalnych operacji.

**03 / AI, wtyczki i integracje**

Buduję i testuję workflow agentowe, integracje narzędzi oraz prototypy wtyczek i Skills. Rozwijam rozwiązania, które mogą być wykorzystane więcej niż jeden raz.

Scalable Book Tracker · Agentic Studio · Product Inventory
